# Las Lilas - Cosmética Natural

Bienvenido a **Las Lilas**, tu sitio web para servicios de estética y cosmética natural artesanal.

## 🌸 Sobre nosotros

En Las Lilas brindamos servicios profesionales de cuidado personal:
- **Pedicuría y Manicuría** - 15 años de experiencia
- **Cejas y Pestañas** - Permanente y tintura natural
- **Cosmética Artesanal** - Jabones, shampoos y cremas 100% naturales

## 🎯 Servicios

### Cuidado Personal
- Pedicuría profesional (tratamiento de hongos, uñas encarnadas, callos)
- Manicuría y uñas esculpidas
- Permanente y tintura de cejas y pestañas

### Productos Naturales
- Jabones artesanales
- Shampoo y crema de enjuague sólido
- Regalos especiales
